# flutter_vlc_player_platform_interface (vendored)

Copied from solid-software/flutter_vlc_player at commit
988a7e67140786fb5510c96e4cb415dbfd837944 (the flutter_vlc_player 7.4.4
release). Its Dart messages were regenerated with Pigeon 25 to match 7.4.4's
Android side, but that version was never published: pub.dev's 2.0.5 (and the
retracted 3.0.0) use the old channel names, so every player call failed with
"Unable to establish connection on channel". Remove this override once a
matching version is published.
