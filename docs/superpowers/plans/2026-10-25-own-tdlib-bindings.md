# Own TDLib Bindings (lumina_tdlib) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace `handy_tdlib_next` with an in-repo package whose Dart API is generated from the same TDLib release (1.8.69) that CI compiles into `libtdjson.so`.

**Architecture:** `packages/lumina_tdlib` is a pure-Dart package. It holds a hand-written FFI client (4 symbols), a TL-schema→Dart code generator, and the generated API, which is committed. A reusable CI workflow builds `libtdjson.so` per ABI from the pinned commit once per input hash and publishes it as a `tdlib-<key>` pre-release. The app workflow downloads it into `android/app/src/main/jniLibs`, the same way the calls engine already works.

**Tech Stack:** Dart 3 (FFI, sealed classes), `package:test`, TDLib `example/android` build scripts, Android NDK r28, GitHub Actions.

**Spec:** this plan's "Context and decisions" section. It records the agreed design: tagged release, own build, own Flutter layer.

## Context and decisions

- **The mismatch:** `handy_tdlib_next` 2.3.16 ships a TDLib **1.8.52** binary but Dart classes generated from the **1.8.36** schema. Fields added since then are dropped, unknown types become `null`, and reshaped types fail silently. The package doesn't publish its generator, so it can't be regenerated.
- **Pin:** TDLib only tags major versions (the last tag is v1.8.0 from 2021). Releases are the "Update version to 1.8.N." commits. The newest is **1.8.69 = `0e88653dcbf4e44c73cb655a05b58cd749a91169`** (2026-10-21).
- **Generated API keeps handy's public shape:** same class names (`Error` → `TdError`), `TdObject`/`TdFunction` sealed bases, `extra`/`clientId`, `fromJson`/`toJson([extra])`/`copyWith`, `defaultObjectId`/`currentObjectId`, `convertMapToObject`/`convertJsonToObject`, `TdPlugin`, and entry points `api.dart` and `client.dart`. Migrating the app is then an import rename plus the real 1.8.36→1.8.69 API changes.
- **Nullability rule** (it matches handy for 1,109 of 1,132 object fields; the rest are doc changes): an object-typed field is nullable iff its TL doc contains "may be null" or "pass null". Primitives and vectors are never null (missing → `0`/`''`/`false`/`[]`). New: a `vector<obj>` whose doc says "may be null" gets nullable elements (`Messages.messages` → `List<Message?>`). handy got this wrong, and `getMessages` with deleted ids failed to parse.
- **int64** is parsed from JSON strings or numbers and sent as strings (TDLib's documented JSON form).
- **Field `extra`** (new in `tonNft`) is renamed to `extraValue`, because `extra` is the request tag on every object.
- **The generator does not run `dart format`.** It emits its own fixed layout, so CI's "generated code is current" check doesn't depend on the formatter version (local Flutter 3.50 beta vs CI 3.47.8).
- **ABIs:** `arm64-v8a` and `x86_64` only, which is what the app ships. Built with NDK 28.2.13676358 at API 24 (the app's minSdk), JSON interface, static OpenSSL 1.1.1w and libc++.
- **Scale of the API change:** 1.8.36 → 1.8.69 adds 1,054 constructors, removes 99 and changes 258. The app code that breaks is listed in Task 5.
- **Communities** exist in 1.8.69 (`community`, `createCommunity`, …). Revisiting D5 is out of scope; Task 6 records it as possible.

## Global Constraints

- TDLib pin: `version=1.8.69`, `commit=0e88653dcbf4e44c73cb655a05b58cd749a91169`. It lives only in `packages/lumina_tdlib/schema/VERSION`.
- NDK `28.2.13676358`, CMake `3.22.1`, Android API level `24`, ABIs `arm64-v8a x86_64`.
- Every LOAD segment of `libtdjson.so` must be 16 KB aligned (`0x4000`).
- No `td_send`/`td_receive`/JSON conversion on the UI isolate. The isolate topology (`lib/core/tdlib/isolates/td_isolates.dart`) is unchanged.
- Package Dart SDK constraint matches the app: `sdk: ^3.13.7`.
- Generated files start with `// GENERATED by tool/generate.dart from schema/td_api.tl. Do not edit.`
- Git: work on branch `tdlib-own-bindings`. **Stage explicit paths only.** The working tree holds the owner's uncommitted local edits (Myket mirrors, AGP, README, pubspec.lock, icons) that must never be staged. When `pubspec.lock` changes for the dependency swap, stage only that hunk (`git add -p pubspec.lock`).
- Never download CI artifacts or release assets locally to verify. Use `gh run view` status and `--log`. `tool/fetch_tdlib.sh` is for the owner to run.
- Pushing the branch to trigger CI is outward-facing: ask the owner before the first push.

## Review Focus

1. **The binary and the schema drift apart again:** CI must fail when `libtdjson.so` isn't the pinned version (`build_tdlib.sh` checks `strings` against `VERSION`), and when `lib/src/tdapi` is stale against `schema/` (Task 5 CI step). Test: Task 3 `version constants match schema/VERSION`.
2. **int64 ids and orders above 2^53** (channel chat positions, `media_album_id`, `effect_id`) arrive as JSON strings. They must parse exactly and encode back as strings. Test: Task 3 `int64 strings round-trip exactly`.
3. **`getMessages` for deleted messages** returns `null` entries. Parsing must succeed with `null` kept in position, not drop the whole result. Test: Task 3 `Messages keeps null entries`.
4. **An object type newer than the schema** (`@type` unknown): top level → `convertMapToObject` returns `null` (the receiver reports a `ParseFailure`). Nested in an abstract field → `FormatException`, which the receiver already catches. Neither may crash the receiver isolate. Test: Task 3 `unknown types`.
5. **Doc text that looks like a tag, or wraps lines** (`//-` continuations, `@param_description` for fields named `description`). The parser must attach every field doc to the right field, or nullability comes out wrong. Test: Task 1 parser tests, plus the real-schema test that every non-builtin constructor has a description.

```dart
/// Model and parser for TDLib's td_api.tl.
library;

/// Declared in the scheme header; never generated.
const _builtinConstructors = {'double', 'string', 'int32', 'int53', 'int64', 'bytes', 'boolFalse', 'boolTrue'};

const _primitiveTypes = {'double', 'string', 'int32', 'int53', 'int64', 'bytes', 'Bool'};

final class TlType {
  const TlType(this.name, [this.element]);

  /// TL type name, or `vector` with [element] set.
  final String name;
  final TlType? element;

  bool get isVector => name == 'vector';
  bool get isPrimitive => _primitiveTypes.contains(name);

  static TlType parse(String source) {
    if (source.startsWith('vector<') && source.endsWith('>')) {
      return TlType('vector', parse(source.substring(7, source.length - 1)));
    }
    return TlType(source);
  }

  @override
  String toString() => isVector ? 'vector<$element>' : name;
}

final class TlField {
  const TlField(this.name, this.type, this.doc);

  final String name;
  final TlType type;
  final String doc;
}

final class TlConstructor {
  const TlConstructor({
    required this.name,
    required this.fields,
    required this.result,
    required this.doc,
    required this.isFunction,
  });

  final String name;
  final List<TlField> fields;

  /// Boxed result type: the abstract class, the class itself, or a function's return type.
  final String result;
  final String doc;
  final bool isFunction;
}

final class TlClass {
  const TlClass(this.name, this.doc);

  final String name;
  final String doc;
}

final class TlSchema {
  const TlSchema(this.classes, this.objects, this.functions);

  final Map<String, TlClass> classes;
  final List<TlConstructor> objects;
  final List<TlConstructor> functions;
}

final _constructor = RegExp(r'^(\w+)((?: \w+:[\w<>]+)*) = (\w+);$');

/// `@key value` pairs; a tag must follow whitespace, so `user@example.com` is text.
final _tag = RegExp(r'(?:^|\s)@(\w+)\s+(.*?)(?=\s@\w+\s|$)');

TlSchema parseTl(String source) {
  final classes = <String, TlClass>{};
  final objects = <TlConstructor>[];
  final functions = <TlConstructor>[];
  var docs = <String, String>{};
  String? lastKey;
  var inFunctions = false;

  void flushClass() {
    final name = docs['class'];
    if (name == null) return;
    classes[name] = TlClass(name, docs['description'] ?? '');
    docs = {};
    lastKey = null;
  }

  for (final raw in source.split('\n')) {
    final line = raw.trim();
    if (line.isEmpty) {
      flushClass();
      continue;
    }
    if (line == '---functions---') {
      flushClass();
      docs = {};
      inFunctions = true;
      continue;
    }
    if (line.startsWith('//')) {
      final text = line.substring(2);
      if (text.startsWith('-')) {
        final key = lastKey;
        if (key != null) docs[key] = '${docs[key]} ${text.substring(1).trim()}'.trim();
        continue;
      }
      final trimmed = text.trimLeft();
      if (trimmed.startsWith('@class') || trimmed.startsWith('@description')) {
        flushClass();
        docs = {};
      }
      for (final m in _tag.allMatches(text)) {
        lastKey = m[1]!;
        docs[m[1]!] = m[2]!.trim();
      }
      continue;
    }

    final m = _constructor.firstMatch(line);
    if (m == null) {
      // Header declarations: `double ? = Double;`, `vector {t:Type} # [ t ] = Vector t;`
      if (line.contains(' ? = ') || line.startsWith('vector {')) continue;
      throw FormatException('Unrecognized TL line', line);
    }
    final name = m[1]!;
    if (_builtinConstructors.contains(name)) {
      docs = {};
      continue;
    }
    final fields = [
      for (final arg in m[2]!.trim().split(' ').where((a) => a.isNotEmpty))
        _field(arg, docs),
    ];
    (inFunctions ? functions : objects).add(
      TlConstructor(
        name: name,
        fields: fields,
        result: m[3]!,
        doc: docs['description'] ?? '',
        isFunction: inFunctions,
      ),
    );
    docs = {};
    lastKey = null;
  }
  return TlSchema(classes, objects, functions);
}

TlField _field(String arg, Map<String, String> docs) {
  final i = arg.indexOf(':');
  final name = arg.substring(0, i);
  // A field called `description` is documented as `@param_description`.
  final doc = docs[name == 'description' ? 'param_description' : name] ?? '';
  return TlField(name, TlType.parse(arg.substring(i + 1)), doc);
}
```

/// Emits the Dart API for a parsed td_api.tl. Output layout is fixed here
/// (no `dart format`), so regenerating is byte-identical on any SDK.
library;

import 'tl.dart';

const _header = '// GENERATED by tool/generate.dart from schema/td_api.tl. Do not edit.\n\n';

/// Pinned TDLib release from schema/VERSION.
final class TdlibVersion {
  const TdlibVersion(this.version, this.commit);

  final String version;
  final String commit;

  factory TdlibVersion.parse(String source) {
    final values = <String, String>{};
    for (final line in source.split('\n')) {
      final i = line.indexOf('=');
      if (i > 0) values[line.substring(0, i).trim()] = line.substring(i + 1).trim();
    }
    final version = values['version'];
    final commit = values['commit'];
    if (version == null || commit == null || !RegExp(r'^[0-9a-f]{40}$').hasMatch(commit)) {
      throw FormatException('schema/VERSION needs version=<x.y.z> and commit=<40 hex digits>', source);
    }
    return TdlibVersion(version, commit);
  }
}

String _cap(String s) => s[0].toUpperCase() + s.substring(1);

String className(String tlName) {
  final name = _cap(tlName);
  return name == 'Error' ? 'TdError' : name;
}

const _generatedMembers = {
  'clientId', 'currentObjectId', 'defaultObjectId', 'copyWith', 'toJson', 'toString', //
  'hashCode', 'runtimeType', 'noSuchMethod',
};

const _dartReserved = {
  'assert', 'break', 'case', 'catch', 'class', 'const', 'continue', 'default', 'do', 'else', //
  'enum', 'extends', 'false', 'final', 'finally', 'for', 'if', 'in', 'is', 'new', 'null', //
  'rethrow', 'return', 'super', 'switch', 'this', 'throw', 'true', 'try', 'var', 'void', //
  'while', 'with',
};

String fieldName(String tlName) {
  final parts = tlName.split('_');
  final camel = parts.first + parts.skip(1).where((p) => p.isNotEmpty).map(_cap).join();
  // TdObject.extra is the request tag; a TL field of that name gets another one.
  if (camel == 'extra') return 'extraValue';
  if (_generatedMembers.contains(camel) || _dartReserved.contains(camel)) {
    throw StateError('TL field "$tlName" collides with a Dart keyword or generated member');
  }
  return camel;
}

String fileName(String tlName) => tlName
    .replaceAllMapped(RegExp('[A-Z]'), (m) => '_${m[0]!.toLowerCase()}')
    .replaceFirst(RegExp('^_'), '');

bool _mayBeNull(String doc) {
  final d = doc.toLowerCase();
  return d.contains('may be null') || d.contains('pass null');
}

bool _isObject(TlType t) => !t.isPrimitive && !t.isVector;

/// Object fields documented as nullable; primitives and vectors never are.
bool _nullable(TlField f) => _isObject(f.type) && _mayBeNull(f.doc);

/// `vector<message>` documented with "may be null" entries (getMessages).
bool _nullableElements(TlField f) =>
    f.type.isVector && _isObject(f.type.element!) && f.doc.toLowerCase().contains('may be null');

String _dartType(TlType t, {bool nullableElements = false}) {
  if (t.isVector) return 'List<${_dartType(t.element!)}${nullableElements ? '?' : ''}>';
  return switch (t.name) {
    'int32' || 'int53' || 'int64' => 'int',
    'double' => 'double',
    'string' || 'bytes' => 'String',
    'Bool' => 'bool',
    _ => className(t.name),
  };
}

String _fieldType(TlField f) =>
    '${_dartType(f.type, nullableElements: _nullableElements(f))}${_nullable(f) ? '?' : ''}';

String _decode(TlType t, String v, {bool nullable = false, bool nullableElements = false}) {
  if (t.isVector) {
    return '_list($v, (e) => ${_decode(t.element!, 'e', nullable: nullableElements)})';
  }
  final plain = switch (t.name) {
    'int32' || 'int53' => '_int($v)',
    'int64' => '_int64($v)',
    'double' => '_double($v)',
    'string' || 'bytes' => '_string($v)',
    'Bool' => '_bool($v)',
    _ => '${className(t.name)}.fromJson(_map($v))',
  };
  return nullable && _isObject(t) ? '$v == null ? null : $plain' : plain;
}

String _encode(TlType t, String v, {bool nullable = false, bool nullableElements = false}) {
  if (t.isVector) {
    final e = t.element!;
    if (e.isPrimitive && e.name != 'int64') return v;
    return '$v.map((e) => ${_encode(e, 'e', nullable: nullableElements)}).toList()';
  }
  if (t.name == 'int64') return '$v.toString()';
  if (t.isPrimitive) return v;
  return nullable ? '$v?.toJson()' : '$v.toJson()';
}

String _doc(String text, String indent) {
  final clean = text.replaceAll('<', '&lt;').replaceAll('>', '&gt;').trim();
  return clean.isEmpty ? '' : '$indent/// $clean\n';
}

void _fields(StringBuffer b, TlConstructor c) {
  for (final f in c.fields) {
    b.write(_doc(f.doc, '  '));
    b.writeln('  final ${_fieldType(f)} ${fieldName(f.name)};');
    b.writeln();
  }
}

void _constructorParams(StringBuffer b, TlConstructor c) {
  for (final f in c.fields) {
    b.writeln('    ${_nullable(f) ? '' : 'required '}this.${fieldName(f.name)},');
  }
}

void _jsonFields(StringBuffer b, TlConstructor c) {
  for (final f in c.fields) {
    final value = _encode(f.type, fieldName(f.name), nullable: _nullable(f), nullableElements: _nullableElements(f));
    b.writeln("    '${f.name}': $value,");
  }
}

void _copyWith(StringBuffer b, TlConstructor c, String name, {required bool override, required bool tagged}) {
  if (override) b.writeln('  @override');
  b.writeln('  $name copyWith({');
  for (final f in c.fields) {
    final type = _fieldType(f);
    b.writeln('    ${type.endsWith('?') ? type : '$type?'} ${fieldName(f.name)},');
  }
  if (tagged) {
    b.writeln('    dynamic extra,');
    b.writeln('    int? clientId,');
  }
  b.writeln('  }) => $name(');
  for (final f in c.fields) {
    final n = fieldName(f.name);
    b.writeln('    $n: $n ?? this.$n,');
  }
  if (tagged) {
    b.writeln('    extra: extra ?? this.extra,');
    b.writeln('    clientId: clientId ?? this.clientId,');
  }
  b.writeln('  );');
}

String _objectClass(TlConstructor c, String parent) {
  final name = className(c.name);
  final b = StringBuffer()
    ..write(_doc(c.doc, ''))
    ..writeln('final class $name extends $parent {')
    ..writeln('  const $name({');
  _constructorParams(b, c);
  b
    ..writeln('    this.extra,')
    ..writeln('    this.clientId,')
    ..writeln('  });')
    ..writeln();
  _fields(b, c);
  b
    ..writeln('  @override')
    ..writeln('  final dynamic extra;')
    ..writeln()
    ..writeln('  @override')
    ..writeln('  final int? clientId;')
    ..writeln()
    ..writeln("  static const String defaultObjectId = '${c.name}';")
    ..writeln()
    ..writeln('  @override')
    ..writeln('  String get currentObjectId => defaultObjectId;')
    ..writeln()
    ..writeln('  factory $name.fromJson(Map<String, dynamic> json) => $name(');
  for (final f in c.fields) {
    final value = _decode(
      f.type,
      "json['${f.name}']",
      nullable: _nullable(f),
      nullableElements: _nullableElements(f),
    );
    b.writeln('    ${fieldName(f.name)}: $value,');
  }
  b
    ..writeln("    extra: json['@extra'],")
    ..writeln("    clientId: json['@client_id'] as int?,")
    ..writeln('  );')
    ..writeln()
    ..writeln('  @override')
    ..writeln('  Map<String, dynamic> toJson() => {')
    ..writeln("    '@type': defaultObjectId,");
  _jsonFields(b, c);
  b
    ..writeln('  };')
    ..writeln();
  _copyWith(b, c, name, override: parent != 'TdObject', tagged: true);
  b.writeln('}');
  return b.toString();
}

String _abstractClass(String tlName, String doc, List<TlConstructor> children) {
  final name = className(tlName);
  final b = StringBuffer()
    ..write(_doc(doc, ''))
    ..writeln('sealed class $name extends TdObject {')
    ..writeln('  const $name();')
    ..writeln()
    ..writeln("  static const String defaultObjectId = '${tlName[0].toLowerCase()}${tlName.substring(1)}';")
    ..writeln()
    ..writeln("  factory $name.fromJson(Map<String, dynamic> json) => switch (json['@type']) {");
  for (final c in children) {
    final child = className(c.name);
    b.writeln('    $child.defaultObjectId => $child.fromJson(json),');
  }
  b
    ..writeln("    _ => throw FormatException('Unknown object \${json['@type']} (expected child of $name)', json),")
    ..writeln('  };')
    ..writeln()
    ..writeln('  $name copyWith();')
    ..writeln('}');
  return b.toString();
}

String _functionClass(TlConstructor c) {
  final name = className(c.name);
  final b = StringBuffer()..write(_doc(c.doc, ''));
  b
    ..writeln('///')
    ..writeln('/// Returns [${className(c.result)}].')
    ..writeln('final class $name extends TdFunction {');
  if (c.fields.isEmpty) {
    b.writeln('  const $name();');
  } else {
    b.writeln('  const $name({');
    _constructorParams(b, c);
    b.writeln('  });');
  }
  b.writeln();
  _fields(b, c);
  b
    ..writeln("  static const String defaultObjectId = '${c.name}';")
    ..writeln()
    ..writeln('  @override')
    ..writeln('  String get currentObjectId => defaultObjectId;')
    ..writeln()
    ..writeln('  @override')
    ..writeln('  Map<String, dynamic> toJson([dynamic extra]) => {')
    ..writeln("    '@type': defaultObjectId,");
  _jsonFields(b, c);
  b
    ..writeln("    '@extra': extra,")
    ..writeln('  };');
  if (c.fields.isNotEmpty) {
    b.writeln();
    _copyWith(b, c, name, override: false, tagged: false);
  }
  b.writeln('}');
  return b.toString();
}

const _objectBase = '''
part of 'tdapi.dart';

  const TdObject();

  /// The `@extra` tag of the request this object answers; null for updates.
  dynamic get extra => null;

  /// The TDLib client that sent this object.

const _helpers = '''
part of 'tdapi.dart';

int _int(Object? v) => v == null ? 0 : (v as num).toInt();

/// TDLib sends int64 as a JSON string; numbers are accepted too.
int _int64(Object? v) => switch (v) {
  null => 0,
  int() => v,
  String() => int.parse(v),
  num() => v.toInt(),
  _ => throw FormatException('Expected an int64, got \$v'),
};

double _double(Object? v) => v == null ? 0.0 : (v as num).toDouble();

String _string(Object? v) => v == null ? '' : v as String;

bool _bool(Object? v) => v == null ? false : v as bool;

Map<String, dynamic> _map(Object? v) => v as Map<String, dynamic>;

List<T> _list<T>(Object? v, T Function(Object? e) item) =>
    v == null ? <T>[] : <T>[for (final e in v as List) item(e)];
''';

Map<String, String> emitLibrary(TlSchema schema, TdlibVersion version) {
  final abstractDocs = <String, String>{for (final c in schema.classes.values) c.name: c.doc};
  for (final o in schema.objects) {
    if (_cap(o.name) != o.result) abstractDocs.putIfAbsent(o.result, () => '');
  }
  final children = <String, List<TlConstructor>>{for (final n in abstractDocs.keys) n: []};
  final standalone = <TlConstructor>[];
  for (final o in schema.objects) {
    if (_cap(o.name) == o.result) {
      if (abstractDocs.containsKey(o.result)) {
        throw StateError('${o.name} is both a constructor and an abstract class');
      }
      standalone.add(o);
    } else {
      children[o.result]!.add(o);
    }
  }

  final files = <String, String>{};
  void put(String path, String content) {
    if (files.containsKey(path)) throw StateError('Two types generate $path');
    files[path] = content;
  }

  for (final MapEntry(key: name, value: doc) in abstractDocs.entries) {
    final parts = [_abstractClass(name, doc, children[name]!), for (final c in children[name]!) _objectClass(c, className(name))];
    put('objects/${fileName(name)}.dart', "${_header}part of '../tdapi.dart';\n\n${parts.join('\n')}");
  }
  for (final o in standalone) {
    put('objects/${fileName(o.name)}.dart', "${_header}part of '../tdapi.dart';\n\n${_objectClass(o, 'TdObject')}");
  }
  for (final f in schema.functions) {
    put('functions/${fileName(f.name)}.dart', "${_header}part of '../tdapi.dart';\n\n${_functionClass(f)}");
  }

  final parts = files.keys.toList();
  put('object.dart', '$_header$_objectBase');
  put('helpers.dart', '$_header$_helpers');
  put(
    'version.dart',
    "${_header}part of 'tdapi.dart';\n\n"
        '/// TDLib release this API was generated from; libtdjson.so must be the same build.\n'
        "const String tdlibVersion = '${version.version}';\n\n"
        "const String tdlibCommit = '${version.commit}';\n",
  );

  final lib = StringBuffer(_header)
    ..writeln('library;')
    ..writeln()
    ..writeln("import 'dart:convert' show json, jsonEncode;")
    ..writeln()
    ..writeln("part 'object.dart';")
    ..writeln("part 'helpers.dart';")
    ..writeln("part 'version.dart';");
  for (final p in parts) {
    lib.writeln("part '$p';");
  }
  lib
    ..writeln()
    ..writeln('/// Parses one TDLib JSON object; null when this schema has no such type.')
    ..writeln("TdObject? convertMapToObject(Map<String, dynamic> map) => switch (map['@type']) {");
  for (final o in schema.objects) {
    final name = className(o.name);
    lib.writeln('  $name.defaultObjectId => $name.fromJson(map),');
  }
  lib
    ..writeln('  _ => null,')
    ..writeln('};')
    ..writeln()
    ..writeln('/// Parses one TDLib JSON string; see [convertMapToObject].')
    ..writeln('TdObject? convertJsonToObject(String? query) =>')
    ..writeln('    query == null ? null : convertMapToObject(json.decode(query) as Map<String, dynamic>);');
  put('tdapi.dart', lib.toString());
  return files;
}

import 'dart:ffi' as ffi;

import 'package:ffi/ffi.dart';

typedef _TdCreateClientIdNative = ffi.Int32 Function();
typedef _TdCreateClientId = int Function();
typedef _TdSendNative = ffi.Void Function(ffi.Int32, ffi.Pointer<Utf8>);
typedef _TdSend = void Function(int, ffi.Pointer<Utf8>);
typedef _TdReceiveNative = ffi.Pointer<Utf8> Function(ffi.Double);
typedef _TdReceive = ffi.Pointer<Utf8> Function(double);
typedef _TdExecuteNative = ffi.Pointer<Utf8> Function(ffi.Pointer<Utf8>);
typedef _TdExecute = ffi.Pointer<Utf8> Function(ffi.Pointer<Utf8>);

/// The four functions of TDLib's JSON interface (td/telegram/td_json_client.h).
///
/// Every call blocks or allocates; keep them off the UI isolate.
class TdPlugin {
  TdPlugin(ffi.DynamicLibrary library) : _lookup = library.lookup;

  /// Opens [libPath] (default `libtdjson.so`, from the app's jniLibs) and sets [instance].
  static Future<void> initialize([String? libPath]) async {
    instance = TdPlugin(ffi.DynamicLibrary.open(libPath ?? 'libtdjson.so'));
  }

  /// The plugin opened by the latest [initialize] in this isolate.
  static late TdPlugin instance;

  final ffi.Pointer<T> Function<T extends ffi.NativeType>(String symbolName) _lookup;

  late final _TdCreateClientId _createClientId =
      _lookup<ffi.NativeFunction<_TdCreateClientIdNative>>('td_create_client_id').asFunction();
  late final _TdSend _send = _lookup<ffi.NativeFunction<_TdSendNative>>('td_send').asFunction();
  late final _TdReceive _receive = _lookup<ffi.NativeFunction<_TdReceiveNative>>('td_receive').asFunction();
  late final _TdExecute _execute = _lookup<ffi.NativeFunction<_TdExecuteNative>>('td_execute').asFunction();

  /// A new client id; the client starts once it is sent its first request.
  int tdCreateClientId() => _createClientId();

  /// Sends a JSON request to [clientId]; the answer arrives via [tdReceive] with the same `@extra`.
  void tdSend(int clientId, String request) {
    final native = request.toNativeUtf8();
    try {
      _send(clientId, native);
    } finally {
      malloc.free(native);
    }
  }

  /// Next response or update for any client, or null after [timeout] seconds.
  ///
  /// The returned buffer belongs to TDLib and is valid until the next call, so it is copied here.
  String? tdReceive([double timeout = 1]) {
    final result = _receive(timeout);
    return result == ffi.nullptr ? null : result.toDartString();
  }

  /// Runs a synchronous TDLib method (e.g. `setLogVerbosityLevel`).
  String? tdExecute(String request) {
    final native = request.toNativeUtf8();
    try {
      final result = _execute(native);
      return result == ffi.nullptr ? null : result.toDartString();
    } finally {
      malloc.free(native);
    }
  }
}

- [ ] **Step 1: Write the build script**

`tool/build_tdlib.sh`:

```bash
#!/usr/bin/env bash
# Builds libtdjson.so for one Android ABI at the TDLib commit pinned in
# packages/lumina_tdlib/schema/VERSION, with TDLib's own example/android
# scripts (JSON interface, static OpenSSL 1.1.1 and libc++).
#   tool/build_tdlib.sh arm64-v8a   ->  build/tdlib/out/arm64-v8a/libtdjson.so
# Needs ANDROID_HOME with "ndk;28.2.13676358" and "cmake;3.22.1", plus gperf,
# php, perl and a JDK (TDLib's check-environment.sh lists them).
set -euo pipefail
abi="${1:?usage: tool/build_tdlib.sh <abi>}"
root="$(cd "$(dirname "$0")/.." && pwd)"
pin="$root/packages/lumina_tdlib/schema/VERSION"
version="$(sed -n 's/^version=//p' "$pin")"
commit="$(sed -n 's/^commit=//p' "$pin")"
ndk_version=28.2.13676358
api_level=24 # the app's minSdk
work="$root/build/tdlib"
out="$work/out/$abi"

mkdir -p "$work"
if [[ ! -d "$work/td/.git" ]]; then
  git init -q "$work/td"
  git -C "$work/td" remote add origin https://github.com/tdlib/td.git
fi
git -C "$work/td" fetch -q --depth 1 origin "$commit"
git -C "$work/td" checkout -q --force FETCH_HEAD

cd "$work/td/example/android"
# 16 KB LOAD alignment (NDK r28 defaults to it; this keeps it explicit).
export LDFLAGS="-Wl,-z,max-page-size=16384"
if [[ ! -d "$work/openssl" ]]; then
  ./build-openssl.sh "$ANDROID_HOME" "$ndk_version" "$work/openssl" OpenSSL_1_1_1w
fi
./build-tdlib.sh "$ANDROID_HOME" "$ndk_version" "$work/openssl" c++_static JSON "$api_level" "$abi"

mkdir -p "$out"
cp "tdlib/libs/$abi/libtdjson.so" "$out/"

# The binary must be the release the Dart API was generated from.
strings "$out/libtdjson.so" | grep -qx "$version" || { echo "libtdjson.so is not TDLib $version" >&2; exit 1; }
if readelf -lW "$out/libtdjson.so" | awk '$1 == "LOAD" && $NF != "0x4000" { bad = 1 } END { exit !bad }'; then
  echo "libtdjson.so has LOAD segments that aren't 16 KB aligned" >&2
  exit 1
fi
ls -l "$out/libtdjson.so"
```

# Prints the cache key of libtdjson.so: a hash of the TDLib pin and the build

`.github/workflows/tdlib.yml`:

```yaml
name: TDLib

# Builds libtdjson.so (TDLib's JSON interface) at the commit pinned in
# packages/lumina_tdlib/schema/VERSION, once per input hash, and publishes it
# as the pre-release tdlib-<key>. The app workflow calls this first and
# downloads the result, so app builds don't recompile TDLib.
on:
  workflow_call:
    outputs:
      key:
        description: TDLib cache key (release tdlib-<key>)
        value: ${{ jobs.key.outputs.key }}
  workflow_dispatch:

permissions:
  contents: write

jobs:
  key:
    runs-on: ubuntu-latest
    outputs:
      key: ${{ steps.key.outputs.key }}
      exists: ${{ steps.key.outputs.exists }}
    steps:
      - uses: actions/checkout@v4
      - id: key
        env:
          GH_TOKEN: ${{ github.token }}
        run: |
          key=$(tool/tdlib_key.sh)
          echo "key=$key" >> "$GITHUB_OUTPUT"
          if gh release view "tdlib-$key" >/dev/null 2>&1; then
            echo "exists=true" >> "$GITHUB_OUTPUT"
            echo "TDLib $key already published"
          else
            echo "exists=false" >> "$GITHUB_OUTPUT"
          fi

  build:
    needs: key
    if: needs.key.outputs.exists != 'true'
    runs-on: ubuntu-latest
    timeout-minutes: 180
    strategy:
      matrix:
        abi: [arm64-v8a, x86_64]
    steps:
      - uses: actions/checkout@v4

      - name: NDK 28.2, CMake 3.22 and TDLib's build tools
        run: |
          yes | "$ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager" --install \
            "ndk;28.2.13676358" "cmake;3.22.1" > /dev/null
          sudo apt-get install -y gperf ninja-build ccache php-cli > /dev/null

      - name: ccache
        uses: actions/cache@v4
        with:
          path: ~/.cache/ccache
          key: tdlib-ccache-${{ matrix.abi }}-${{ needs.key.outputs.key }}
          restore-keys: tdlib-ccache-${{ matrix.abi }}-

      - name: Build
        env:
          CMAKE_C_COMPILER_LAUNCHER: ccache
          CMAKE_CXX_COMPILER_LAUNCHER: ccache
          CCACHE_MAXSIZE: 3G
          CCACHE_SLOPPINESS: pch_defines,time_macros,include_file_mtime,include_file_ctime
          # TDLib's big translation units need ~2-3 GB each.
          CMAKE_BUILD_PARALLEL_LEVEL: 3
        run: |
          tool/build_tdlib.sh ${{ matrix.abi }}
          ccache -s | tail -n 5
          mkdir -p dist
          cp "build/tdlib/out/${{ matrix.abi }}/libtdjson.so" "dist/libtdjson-${{ matrix.abi }}.so"

      - uses: actions/upload-artifact@v4
        with:
          name: tdlib-${{ matrix.abi }}
          path: dist/*.so
          retention-days: 3

  publish:
    needs: [key, build]
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/download-artifact@v4
        with:
          pattern: tdlib-*
          merge-multiple: true
          path: dist
      - env:
          GH_TOKEN: ${{ github.token }}
          KEY: ${{ needs.key.outputs.key }}
        run: |
          version=$(sed -n 's/^version=//p' packages/lumina_tdlib/schema/VERSION)
          commit=$(sed -n 's/^commit=//p' packages/lumina_tdlib/schema/VERSION)
          (cd dist && sha256sum *.so > SHA256SUMS.txt && ls -l)
          gh release create "tdlib-$KEY" --repo "$GITHUB_REPOSITORY" \
            --prerelease --target "$GITHUB_SHA" \
            --title "TDLib $version ($KEY)" \
            --notes "libtdjson.so for arm64-v8a and x86_64: TDLib $version at tdlib/td@${commit::9} (BSL-1.0), built by tool/build_tdlib.sh from ${GITHUB_SHA::7}. Used by the app builds; not an app release." \
            dist/*.so dist/SHA256SUMS.txt \
            || gh release view "tdlib-$KEY" --repo "$GITHUB_REPOSITORY" > /dev/null
```
